# Brand spec — Chronos / «Фембойские шалости на техах»

- Сервер: Chronos. Название интерфейса: «Фембойские шалости на техах».
- Кодекс: «каждый тех - фембой и это точка».
- Референс по настроению: «Пепельный Щит» (не копировать структуру/контент).
- Основная палитра: фон `#100d16`, панели `#17131f` / `#1d1727`, золото `#c6a66b`, светлое золото `#e1c58e`, текст `#eee8e1`.
- Типографика: Cormorant Garamond для крупных заголовков и Manrope для интерфейса.
- Геометрия: строгие небольшие скругления, тонкие золотые линии, сдержанный орнамент.
- Анимация: короткие переходы 180–220 мс, без резких свечений.
- Логотип/герб: временный геометрический знак щита в интерфейсе; финальный фирменный герб требует утверждения.
- Ассеты: собственные декоративные элементы CSS; внешние изображения не используются.
